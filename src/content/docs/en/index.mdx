## How this course works

<CardGrid>
  <Card title="The model first, then the code" icon="rocket">
    Every lesson starts from the AMQP model — producers, exchanges, bindings, queues, consumers — so the code is obvious once you can see how a message flows.
  </Card>
  <Card title="Three languages side by side" icon="seti:config">
    Producer and consumer examples in Node (amqplib), Python (pika), and Go (amqp091) through synced tabs — pick your language once and follow it everywhere.
  </Card>
  <Card title="Design, not just syntax" icon="approve-check">
    Every topic covers the why and the trade-offs — when to ack manually, how to guarantee delivery, how to handle poison messages, and when a queue is the wrong tool.
  </Card>
  <Card title="Diagrams that explain" icon="puzzle">
    Exchange routing, acknowledgement flow, dead-letter retry, and RPC correlation as theme-aware Mermaid diagrams. Bilingual (English / ไทย) with saved quiz progress.
  </Card>
</CardGrid>

*Verified against RabbitMQ 4.3.x (server 4.3.6, Erlang/OTP 27) running the official `rabbitmq:4-management` Docker image, `amqplib` 2.0.x, `pika` 1.4.x, and `amqp091-go` 1.15.x.*
